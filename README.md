# Interfaz Arquitectura

Interfaz web desarrollada en HTML y CSS como propuesta visual para la aplicación de la Universidad de La Sabana.

## 📱 Descripción

Este proyecto contiene la recreación de una interfaz móvil con diferentes secciones de la aplicación, incluyendo:

- 🏠 Pantalla de inicio
- 🚨 Sección de alertas
- 📋 Reporte de objetos o espacios dañados
- 📰 Actualidad Unisabana
- 👤 Perfil y navegación
- 🏫 Comunidades

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub Pages
